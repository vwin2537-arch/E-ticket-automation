# คู่มือใช้งานบน Windows — ระบบจองบัตรเอราวัณ

ระบบนี้ช่วยกรอกฟอร์มจองบัตรเข้าอุทยานเอราวัณในเว็บ DNP ให้อัตโนมัติ
**กรอกถึงหน้าสรุปแล้วหยุด — คนใช้ตรวจยอดแล้วกดจ่ายเอง** (ระบบไม่จ่ายเงินแทน)

---

## ส่วนที่ 1 — ติดตั้งบนเครื่อง Windows (ทำครั้งเดียว) 🛠️

### 1) แตกไฟล์ zip
แตกไฟล์ `dnp-eticket-autofill-Windows.zip` ที่พี่วินส่งให้ → ได้โฟลเดอร์ `dnp-eticket-autofill`
เอาไปวางไว้ที่ไหนก็ได้ เช่นหน้า Desktop

> ในไฟล์ zip มีไฟล์ login ของพี่วิน (`auth`) มาให้แล้ว และตัดส่วนที่ไม่จำเป็นออกแล้ว
> ลูกน้อง**ไม่ต้อง login เอง**

### 2) ติดตั้ง Node.js (ถ้าเครื่องยังไม่มี)
- เปิดเว็บ **https://nodejs.org** → โหลดปุ่มฝั่งซ้าย (LTS) → ติดตั้งแบบกด Next ไปเรื่อยๆ

### 3) ดับเบิลคลิก `1-SETUP-Windows.bat`
รอจนขึ้น **"Setup complete!"** (ใช้เวลาสักพัก เพราะโหลดเบราว์เซอร์ ~150MB)

---

## ส่วนที่ 2 — ใช้งานทุกวัน (ลูกน้องทำ) ▶️

1. ดับเบิลคลิก **`2-START-Windows.bat`**
   - จะมีหน้าต่างดำขึ้นมา → **ห้ามปิด** จนกว่าจะเลิกใช้
   - เบราว์เซอร์จะเปิดหน้ากากให้เองที่ http://localhost:5179
2. ดูแถบบนสุด:
   - 🟢 **เขียว = พร้อมจอง**
   - 🔴 **แดง = login หลุด** → แจ้งพี่วิน (ต้องเอาไฟล์ login ใหม่มาให้)
3. กรอก: วันที่ → รอบเวลา → รถ → จำนวนคน → กด **"ยืนยัน"**
4. เบราว์เซอร์อีกหน้าจะเด้งขึ้น กรอกให้อัตโนมัติจนถึง **หน้าสรุป** แล้วหยุด
5. **ตรวจยอด แล้วกดจ่ายเอง** ในหน้านั้น

### เลิกใช้งาน — กดปุ่ม "⏻ ปิดการทำงาน" ในหน้ากาก ⛔ อย่าปิดหน้าต่างดำเอง
- เลื่อนหน้ากากลงล่างสุด → กดปุ่มแดง **"⏻ ปิดการทำงาน — เลิกใช้วันนี้"** → กดยืนยัน **"ปิดเลย"**
- ระบบจะเก็บเบราว์เซอร์ให้เรียบร้อย ส่ง log ให้หัวหน้า แล้ว **หน้าต่างดำปิดเอง** — ไม่ต้องไปกดอะไรในหน้าต่างดำ
- ⛔ **ห้ามกดกากบาทปิดหน้าต่างดำเอง** — ถ้าปิดผิดจังหวะ เบราว์เซอร์ของบอทจะค้างเต็มจอ ระบบเพี้ยน
  (เผลอปิดไปแล้ว → ดูวิธีกู้ในตารางล่าง)

---

## ปัญหาที่อาจเจอ + วิธีแก้ 🩹

| อาการ | แก้ยังไง |
|-------|----------|
| **เผลอปิดหน้าต่างดำ / เบราว์เซอร์บอทค้างเต็มจอ ระบบเพี้ยน** | ดับเบิลคลิก **`RESET-Windows.bat`** → กวาดของค้าง + เปิดระบบใหม่ให้อัตโนมัติ คลิกเดียวจบ |
| แถบบนสุดขึ้น 🔴 แดง "ออกจากระบบแล้ว" | login หมดอายุ — พี่วินก๊อปไฟล์ `auth\storageState.json` ใหม่มาทับ |
| เปิด .bat แล้วเด้งปิดทันที | ยังไม่ได้ติดตั้ง — รัน `1-SETUP-Windows.bat` ก่อน |
| ขึ้น "node ไม่ใช่คำสั่ง..." | ยังไม่ได้ลง Node.js — ดูส่วนที่ 1 ข้อ 2 |
| กรอกแล้วบอท error วันเต็ม/ปิดรับ | เลือกวันอื่น (จองล่วงหน้าได้ 7 วัน, ปิดรับ 15:30) |

## 📊 รายงานการใช้งาน
ทุกครั้งที่กด "ยืนยัน" ระบบบันทึกลงไฟล์ **`logs\usage.csv`** อัตโนมัติ
(วันเวลา/วันที่จอง/จำนวนคน/รถ/ยอดเงิน/เวลาที่ใช้/ผล) — ดับเบิลคลิกเปิดด้วย Excel
แล้วทำ PivotTable สรุปรายวัน/รายเดือนได้เลย ภาษาไทยไม่เพี้ยน
> แต่ละเครื่องเก็บ log ของตัวเอง — ถ้าอยากรวมรายงาน ก๊อปไฟล์ `usage.csv` มารวมเอง
>
> 📤 **ส่งขึ้น Google Drive อัตโนมัติ:** ทุกครั้งที่กดปุ่ม **"⏻ ปิดการทำงาน"** หรือใช้ **`RESET-Windows.bat`**
> ระบบจะส่ง log (`usage.csv` + log การทำงาน) ขึ้น Google Drive ของหัวหน้าให้เอง — หัวหน้าดูบัค/ติดตามการใช้งานจากที่ไหนก็ได้ ไม่ต้องมานั่งหน้าเครื่อง

## ⚠️ เรื่องที่พี่วินควรรู้
- ไฟล์ `auth\storageState.json` = กุญแจเข้าระบบ DNP ในนามพี่วิน
  ใครถือเครื่องนี้ = จองในนามพี่วินได้ ระวังการเข้าถึงเครื่อง
- ระบบ**หยุดก่อนจ่ายเงินเสมอ** — ไม่มีการตัดเงินอัตโนมัติ
- session อยู่ได้นาน (~1 ปี) ปกติไม่ต้องเปลี่ยนไฟล์ login บ่อย
